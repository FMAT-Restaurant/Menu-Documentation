# MVP-1 — Catálogo publicable

## 1. Alcance

Este plan implementa la primera entrega de la ERS Menu 2.1.1 con los equipos Front y Back. Permite administrar categorías, identidad comercial, ofertas y composición básica, y consultar ofertas publicables. Para completar una oferta en este MVP se usa un artículo referenciado de Inventario como contenido; las otras fuentes de contenido se completan en MVP-2.

La API se implementa conforme a las operaciones de docs/contracts/api-contract.md. El MVP no afirma la implementación completa de los cuatro modos de ComponentSource: hasta MVP-2, los clientes de esta entrega solo pueden crear y consultar alternativas INVENTORY_ITEM. La composición sigue las reglas de docs/ers/business-rules.md y docs/ers/traceability.md. La selección concreta de opciones de una orden y el precio final siguen fuera de Menu.

La mezcla de operaciones y el dataset siguen pendientes bajo OPEN-009; la elección de herramienta de generación de carga es una cuestión técnica independiente de la sección 4.
