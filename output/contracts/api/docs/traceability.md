# Matriz de trazabilidad de la API síncrona de Menu

Esta matriz audita la propuesta OpenAPI 0.1.1 frente a la [ERS 1.3.12](../../../ers/README.md) y a [`proposal.md`](../../proposal.md). La primera vista parte de cada par método/ruta; la segunda parte de cada uno de los **86 elementos normativos**. La declaración y verificación originales siguen en la ERS; la semántica del HTTP propuesto está en OpenAPI. Una relación indica dónde se **representa o explica** una obligación, no que exista implementación ni aceptación en ejecución.

## Cuestiones abiertas y decisiones de wire

| Cuestión | Representación en esta propuesta |
| --- | --- |
| `OPEN-002` | `ComboOptionBatchResult`, errores 409/422 y resultados por destino son propuesta; catálogo definitivo de códigos y aislamiento/concurrencia del lote no se fijan. |
| `OPEN-007` | Bearer, `x-access-class`, paginación y actualización del catálogo son decisiones técnicas provisionales. El contrato POS → Orders + Kitchen, recepción de señales y transporte de eventos quedan fuera de este OpenAPI de Menu. |
| `OPEN-009` | `ComboOption` permite varias opciones distintas hacia la misma variante; repetición de una misma opción concreta en una orden y sus instancias no se deciden aquí. |
| `OPEN-010` | Los esquemas usan `number` lógico sin moneda, escala, signo ni redondeo cerrados. La fórmula del combo de `BR-MENU-008` se documenta, sin inventar agregación de modificadores de variantes hoja. |
| `OPEN-011` | `PATCH enabled=false` representa retiro conservando identidad; `DELETE` expresa las condiciones lógicas de la ERS sin elegir tablas históricas, tombstones, plazos o mecanismo físico. |

## Criterio de auditoría

La vista de operaciones debe contener una fila por cada par de `proposal.md` y cada identificador normativo de la ERS debe aparecer exactamente una vez como fila en la vista inversa. Los `x-ers-refs` indican trazabilidad directa por operación; los elementos transversales o fuera del ownership de Menu tienen ubicación y motivo explícitos. La matriz no sustituye las restricciones, descripciones ni esquemas OpenAPI.
